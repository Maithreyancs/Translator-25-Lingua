About LinguaVoice Architecture

An accessible, modular web application combining multi-provider neural translation with native Web Speech API synthesis for 25+ global and regional languages.

1. Project Overview & Objectives

LinguaVoice is an interactive web-based multilingual sentence translator and speech synthesis application designed to bridge language barriers. It allows users to enter or dictate a sentence in any source language, translate it with high fidelity into a selected target language, and immediately synthesize natural speech using the browser's native Web Speech API.

Unlike visual-only demo translators, LinguaVoice dynamically links language selection directly to both translation API parameters and Text-to-Speech (TTS) locale engines.

🌐 Multi-tier Translation

Primary Google GTX endpoint with MyMemory fallback and offline phrasebook. Zero mandatory API keys required.

🎙️ Dynamic Speech Synthesis

Real TTS via Web Speech API with automatic voice matching for Tamil, Hindi, Telugu, Malayalam, Japanese, and more.

🎛️ Complete Voice Controls

Play, Pause, Resume, Stop, Replay, dynamic voice selection, and fine-grained 0.5x–2.0x speech speed adjustment.

📜 History & Favorites

Persistent storage using browser localStorage with duplicate prevention, instant replay, and star favorites.

4. Technical Implementation

How Translation Works:

When a translation is requested, TranslatorController validates the input and calls translationService.translate(text, sourceLang, targetLang). The service queries Google's GTX single translation endpoint, concatenates multi-segment sentences, detects the input language when "Auto Detect" is used, and caches the result. If a network interruption occurs, it automatically fails over to the MyMemory API or the local offline phrasebook.

How Text-to-Speech Works:

Speech synthesis utilizes the standardized window.speechSynthesis API. When a language is selected, SpeechEngine queries installed voices via getVoices() and filters matching voices for the target speech code (e.g. ta-IN for Tamil). When the user clicks Translate & Speak or Play, a new SpeechSynthesisUtterance is configured with the selected speed (0.5x–2.0x), pitch, and voice, then dispatched to the speech synthesizer.

Keyboard Shortcuts:

  • Ctrl + Enter : Translate and speak output
  • Alt + P : Play / Pause audio
  • Alt + S : Stop audio playback
  • Alt + X : Swap source & target languages
  • Alt + C : Clear text input
